Join a different household

Switches your login to another household's data. You'll stop seeing this household's pantry and start seeing the one for the code you enter — use this if you signed up before getting the right invite code.

Household members

Everyone who's logged in shows up here automatically. Roles are for your own organization — a "Kid" role hides the Spending and Settings tabs for that person.

Roles are a convenience, not a security boundary: the shared login means anyone signed in can still see and edit everything if they really want to — Firestore isn't set up to enforce per-role permissions.

Household activity

Who added, removed, or changed what — so everyone sharing this pantry can stay in sync.

Backup your data

Everything above syncs automatically to your household's shared account, so you don't need to click Save. These buttons are for an extra offline backup file, or to start completely fresh.
